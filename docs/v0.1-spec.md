# NekoLang v0.1 Spec

## 目标

NekoLang v0.1 的目标是提供一门小型、可编译、可生成二进制可执行文件的教学语言。

v0.1 的重点不是覆盖尽可能多的语言特性，而是保证：

- 语法清晰
- 前端与后端能力一致
- 能稳定生成可执行文件

## 编译模型

v0.1 采用以下编译链路：

1. 源代码 `.neko`
2. 词法分析
3. 语法分析
4. 语义分析
5. LLVM IR 生成
6. 或在 Apple Silicon macOS 上生成 ARM64 汇编
7. `clang` 链接运行时与项目内 C 源码
8. 二进制可执行文件

v0.1 不包含解释执行模式。

## 推荐语法

推荐使用标准关键字：

- `program`
- `var`
- `begin`
- `:=`
- `if`
- `while`
- `print`
- `function`
- `lambda`
- `array`
- `array-set`
- `array-print`
- `import`
- `extern`

兼容别名由实现保留，但文档、示例和测试应优先使用标准关键字。

## 计划支持的类型

v0.1 计划支持：

- `int`
- `float`
- `char`
- `bool`
- `string`
- `pointer`
- `(array <type> <size>)`
- `(func (<type> ...) <type>)`

备注：

- `string` 已可作为变量类型使用，并支持字符串操作
- `pointer` 是 opaque pointer，仅用于 extern 间透传 C 句柄

## 计划支持的语句与结构

v0.1 计划支持：

- 程序入口 `program`
- 变量声明 `var`
- 赋值 `:=`
- 复合语句 `begin`
- 条件语句 `if`
- 循环语句 `while`
- 输出 `print`
- 函数定义 `function`
- 返回语句 `return`
- lambda 表达式 `lambda`
- 数组声明与数组操作
- 字符串类型 `string` 与字符串操作
- 字符字面量与字符操作
- 多文件导入 `import`
- 外部函数声明 `extern`

## 计划支持的能力

v0.1 目标内的能力：

- 算术运算
- 比较运算
- 函数调用
- lambda 表达式与函数类型（高阶函数）
- 字符串拼接、长度、切片、比较、包含检查、int↔string 转换
- 字符字面量、char↔int 转换、字符分类与大小写转换
- 一维数组
- 多文件导入，导入文件可提供 `function` 和 `extern`
- 固定签名 C extern 调用
- 项目内 C 源码自动发现、显式链接配置
- 生成 LLVM IR
- 在 Apple Silicon macOS 上生成 ARM64 汇编
- 编译为可执行文件
- 命令行参数
- 基础文件读写
- 统一 CLI 命令入口和项目级 `nekgo` 工具

## 工具链范围

v0.1 同时提供单文件编译器 CLI 和轻量项目管理工具。

v0.1 建议支持的命令形态：

- `neko check <file>`
- `neko build <file> -o <output>`
- `neko run <file>`
- `neko llvm-ir <file>`

类似 `cargo` 的项目工具，例如：

- `nekgo new`
- `nekgo build`
- `nekgo run`
- `nekgo test`
- `nekgo clean`

已经进入当前实现范围。默认行为尽量与 `cargo` 对齐，例如 `build` 与 `run` 默认复用项目内 `build/` 目录；偏离默认习惯的临时运行通过 `nekgo run --ephemeral` 显式开启。

## 当前实现已具备的部分

截至当前仓库状态，以下能力已经存在：

- 词法分析、语法分析、AST
- 符号表与四元式
- 基本控制流
- 一维数组的基础支持
- 函数定义、函数调用与 `return`
- lambda 表达式、`(func ...)` 函数类型、函数作为值传递
- `string` 类型、字符串操作（拼接、长度、切片、比较、包含、转换）
- `pointer` 类型与 opaque pointer 空值语义
- 字符字面量、`char` 操作（转换、分类、大小写）
- `bool` 类型与比较表达式
- 多文件导入、导入链解析和循环导入检查
- 固定签名 `extern` 声明
- 项目内 C 源码自动发现和链接
- 命令行参数读取
- 基础文件读写
- LLVM 后端的表达式、控制流与函数生成
- Apple Silicon macOS ARM64 后端
- 通过 `clang` 生成可执行文件
- `check`、`build`、`run`、`llvm-ir` 等统一 CLI 入口
- `nekgo new/build/run/test/clean` 项目命令

## 当前实现尚未完整具备的部分

这些内容属于 v0.1 路线内，但当前还未完整完成：

- 更细的运行时错误信息
- 跨平台构建说明与发布说明
- `extern` 的 `void`、可变参数、数组参数支持
- `pointer` 的内存安全诊断

## 非目标

以下内容不属于 v0.1：

- 解释器
- REPL
- 包管理和版本解析
- 面向对象特性
- 垃圾回收
- 激进优化
- NekoLang 侧直接解引用 pointer

## v0.1 验收标准

当满足以下条件时，可以认为 v0.1 达成：

- 能编译多函数程序
- 能稳定生成二进制可执行文件
- 能处理基本控制流和一维数组
- 能使用命令行参数和基础文件读写
- 能通过 `import` 组织多文件程序
- 能通过 `extern` 和项目内 C 源码连接简单原生能力
- 文档、测试、实现三者一致
