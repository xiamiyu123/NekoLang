# NekoLang v0.1 Spec

## 目标

NekoLang v0.1 的目标是提供一门小型、可编译、可生成二进制可执行文件的教学语言。

v0.1 的重点不是覆盖尽可能多的语言特性，而是保证：

- 语法清晰
- 前端与后端能力一致
- 能稳定生成可执行文件

## 编译模型

v0.1 采用以下编译链路：

1. 源代码 `.neko`
2. 词法分析
3. 语法分析
4. 语义分析
5. LLVM IR 生成
6. `clang` 链接运行时
7. 二进制可执行文件

v0.1 不包含解释执行模式。

## 推荐语法

推荐使用标准关键字：

- `program`
- `var`
- `begin`
- `:=`
- `if`
- `while`
- `print`
- `function`
- `lambda`
- `array`
- `array-set`
- `array-print`

兼容别名由实现保留，但文档、示例和测试应优先使用标准关键字。

## 计划支持的类型

v0.1 计划支持：

- `int`
- `float`
- `char`
- `bool`
- `(array <type> <size>)`
- `(func (<type> ...) <type>)`

备注：

- 当前仓库已经稳定支持 `int`、`float`、`char`、`bool`
- 字符串字面量仅用于运行时接口，例如文件路径，不作为可声明变量类型

## 计划支持的语句与结构

v0.1 计划支持：

- 程序入口 `program`
- 变量声明 `var`
- 赋值 `:=`
- 复合语句 `begin`
- 条件语句 `if`
- 循环语句 `while`
- 输出 `print`
- 函数定义 `function`
- 返回语句 `return`
- lambda 表达式 `lambda`
- 数组声明与数组操作

## 计划支持的能力

v0.1 目标内的能力：

- 算术运算
- 比较运算
- 函数调用
- lambda 表达式与函数类型（高阶函数）
- 一维数组
- 生成 LLVM IR
- 编译为可执行文件
- 命令行参数
- 基础文件读写
- 统一 CLI 命令入口

## 工具链范围

v0.1 只承诺提供“编译器前端 CLI”，不承诺完整项目管理工具。

v0.1 建议支持的命令形态：

- `neko check <file>`
- `neko build <file> -o <output>`
- `neko run <file>`
- `neko llvm-ir <file>`

类似 `cargo` 的项目工具，例如：

- `neko new`
- `neko init`
- `neko build`
- `neko run`

不属于 v0.1 的硬性范围，可在后续版本引入。

## 当前实现已具备的部分

截至当前仓库状态，以下能力已经存在：

- 词法分析、语法分析、AST
- 符号表与四元式
- 基本控制流
- 一维数组的基础支持
- 函数定义、函数调用与 `return`
- lambda 表达式、`(func ...)` 函数类型、函数作为值传递
- `bool` 类型与比较表达式
- 命令行参数读取
- 基础文件读写
- LLVM 后端的表达式、控制流与函数生成
- 通过 `clang` 生成可执行文件
- `check`、`build`、`run`、`llvm-ir` 等统一 CLI 入口

## 当前实现尚未完整具备的部分

这些内容属于 v0.1 路线内，但当前还未完整完成：

- 更多端到端 demo
- 更细的运行时错误信息
- 跨平台构建说明与发布说明

## 非目标

以下内容不属于 v0.1：

- 解释器
- REPL
- 包管理
- 模块系统
- 面向对象特性
- 垃圾回收
- 激进优化
- 完整项目管理工具

## v0.1 验收标准

当满足以下条件时，可以认为 v0.1 达成：

- 能编译多函数程序
- 能稳定生成二进制可执行文件
- 能处理基本控制流和一维数组
- 能使用命令行参数和基础文件读写
- 文档、测试、实现三者一致
